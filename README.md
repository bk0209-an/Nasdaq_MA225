# Nasdaq MA225 신호

QQQ 종가 vs 225일 이동평균으로 오늘 국내장에서 할 행동을 알려주는 스크립트.

| 어제 → 오늘 | 행동 |
|---|---|
| 2배 → 2배 | 2배 보유 |
| 2배 → 1배 | 2배 매도 후, 1배 매수 |
| 1배 → 1배 | 1배 보유 |
| 1배 → 2배 | 1배 매도 후, 2배 매수 |

- 2배: TIGER 미국나스닥100레버리지(합성) 418660
- 1배: TIGER 미국나스닥100 133690
- 미국 d일 종가로 판정 → 국내 d 다음 거래일에 체결

```bash
pip install -r requirements.txt
python signal_daily.py
```

출력 첫 줄이 알림용 한 줄 요약이다. 평일 아침 Claude Code 클라우드 루틴이 실행해 푸시로 보낸다.

*과거 데이터 기반 규칙의 신호일 뿐이며 투자 권유가 아닙니다.*
